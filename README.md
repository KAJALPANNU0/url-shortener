# 🔗 URL Shortener

A simple backend URL Shortener application built using Spring Boot and PostgreSQL. This project generates a unique short code for a given long URL and stores the mapping in a PostgreSQL database.

## 🚀 Features

- Shorten long URLs
- Store URL mappings in PostgreSQL
- REST API built with Spring Boot
- Layered architecture (Controller, Service, Repository)

## 🛠️ Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- Thunder Client

## 📁 Project Structure

```
src
├── controller
├── service
├── repository
├── entity
└── resources
```
